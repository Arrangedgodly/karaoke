## Priority Issues

1. [P2] README teaches retired interactions — "Reorder by cord — drag from a jack point", "free board", "dropdown + Load", chips "All, Warm, Rock, Funny, Speech" (actual: All / Warm / Big echo / Deep voices / Robotic / Funny / Clean & clear), and the screenshot alt text still says "cord board". Why: this is the operator's printed manual for a dark venue with no internet; following it wastes the before-doors window and erodes trust. Fix: rewrite the Advanced/Preset/chip passages to the shipped row-reorder + searchable-list UI, regenerate the alt text; consider a doc-verb lint in CI. ($impeccable document)
2. [P2] Human undo is invisible at the point of need — human entries restore silently, the toast never relabels for them, and README documents Undo only under agent control. Why: the product's own success promise ("understand what changed, undo it") fails for a non-engineer who doesn't know Ctrl/Cmd+Z. Fix: surface a transient undo affordance for human structural edits (reuse the toast slot with the operator label), or teach the shortcut once at the first accepted human edit. ($impeccable harden)
3. [P2] Simple's library decision point: 7 filter chips + search (over the ≤4 guidance), with no chip parity in Advanced. Why: two narrowing vocabularies for one library force relearning across views. Fix: prune to the 4–5 highest-coverage chips or generate from taxonomy axes; decide whether both views share one narrowing vocabulary. ($impeccable distill)
4. [P3] Alt+ArrowLeft/Right board reorder lives only in the grip's aria-label. Why: a sighted keyboard operator cannot discover the board's one keyboard gesture. Fix: one visible micro-hint on grip focus — the register's help line is the natural slot. ($impeccable clarify)
5. [P3] Deck status sentence at the 12px value tier — smallest prose on the deck — against the product's own distance-readability gate. Why: mid-show glances from 2 m read lamp + word; the word is the small one. Fix: lift the sentence one type step (leave RATE/LAT/NODES subordinate) or add weight. ($impeccable typeset)

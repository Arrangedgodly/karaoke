## Verdict on the redesign (before/after vs baseline 36/40)

**Held at 36/40 — but the 36 is now earned in a harder world.** The
baseline's three P3s were: (a) size/shadow tokenization gap — PAID: the
value-display ladder is a documented two-tier grammar and the fresh
DESIGN.md frontmatter now carries the real ramp (0.9/1.05rem absorbed as
truth this run); (b) agent-side 0..1 vs 0–100 % seam — agent-side,
untouched by this run; (c) get_capabilities length — agent-side,
untouched. Against that, the new world added one genuine new cost (cord
discoverability, P2 below) and inherited the standing behavioral residue

(one coherent instrument metaphor, zero glow, one accent), issue mass
down (detector 25 → 15), score flat. Honest.

## Strongest three wins

1. **One machine mouth (H1, and the redesign's thesis made true).** The
   display register answers every control path — native keyboard, drag,
   wheel, agent fast-path all land in one place — with fixed geometry
   that can never pump layout, while the pinned OUT VU corner keeps
   output truth visible in every state including bypass. Status visibility
   is now structural, not decorative.
2. **The physical metaphor completed (H2).** Jacks, keys, knobs with
   detent ticks, machined grooves, and patch cords whose editing
   semantics match real patch bays (reorder = re-patch; incomplete link
   = no change; drop nowhere = revert). The cord layer also made order
   visible as geometry — the strongest real-world match in the project's
   history.
3. **Consistency as grammar, not rulebook (H4).** One disabled texture
   for exactly two states, one key vocabulary deck-wide, one value
   ladder verified computed (nothing between 12px and 13.6px), family
   color derived from a single `data-family` rule per family. The
   detector's quality findings collapsed from takeover's raw-rem drift
   to a confined, documented residual.

## Strongest three gaps

1. **P2 — cord-editing affordance is recall-only.** The jack rings are
   15px print-dim circles; nothing on the resting surface teaches that
   dragging a cord reorders the chain (the README teaches it, the face
   does not). The board's signature interaction carries its own
   discoverability burden. Fix shape (unfunded): a persistent first-run
   hint or a hot-ring hover state that names the gesture.
2. **P3 — the off-chassis residual still speaks the retired world.**
   Agent toasts, the watchdog Restore key, and the ?dev harness keep the
   rq5 amber vocabulary (0.8rem/6px/8px islands, rgba blacks) against a
   Pattern Machine page — the detector's remaining 12 quality findings
   all live in lines 2623–2968. Documented residual (DESIGN.md records
   it), but the toast is a high-frequency surface; the drift is visible.
3. **P3 — standing behavioral residue, unchanged by the visual pass.**
   No undo for manual knob/board edits (H3), no numeric value entry
   (H7), help discovery hover/focus-only (H6), 9px canvas meter numerals
   (recorded exception). None are visual; all predate the redesign.

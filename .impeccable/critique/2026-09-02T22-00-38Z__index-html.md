## Priority Issues

1. [P1] Simple view is silent during emergency bypass — toggleBypass() (src/main.js:112) updates deck + Advanced canvas hatch, never the Simple stage. Fix: SimpleView.onBypassChanged() giving the stage the recede + "BYPASSED — effects off" line (meters excluded). ($impeccable harden)
2. [P1] No undo for human edits — pushAgentUndo (src/chain-editing.js:534) gates on source==='agent'; stack/Ctrl+Z/conflict machinery all exist but feed only agent edits. Fix: push human structural/param edits with operator labels, reusing noteHumanEdit. ($impeccable shape)
3. [P2] --pm-print-dim misses AA (4.465 chassis / 4.184 slab) and DESIGN.md's recorded 5.26 is wrong (docs/redesign.md missing). Fix: lift token (~#7d8398 clears slab) and correct recorded figures. ($impeccable audit)
4. [P2] Spacebar emergency bypass dead across the encoder field — Space handler skips all INPUTs; knobs are input[type=range] with no native Space meaning. BUTTON skip is correct (chip activation). Fix: let range inputs pass Space. ($impeccable audit)
5. [P2] Advanced Presets panel fragments 33 presets under ~27 one-item h4 category headers in a 260px column; disagrees with Simple's flat filtered list. Fix: header only when >=2 visible rows, or collapse to four taxonomy axes. ($impeccable distill)
6. [P2] Promised preset-transfer UI does not exist — no Blob/createObjectURL/FileReader/download path anywhere in src/ while DESIGN.md + PRODUCT.md specify Import/Download with Rename/Replace/Cancel collisions. Fix: build per contract or annotate as unshipped. ($impeccable shape)

## Persona Red Flags

Alex (power user): no search-focus shortcut; Previous/Next buttons only; no batch gestures (fold-all, bypass-all); Ctrl+Z never answers Alex's own edits.

Sam (screen-reader + keyboard-only): every Sounds row accname swallows the full 2-line description (33 rows of verbosity; name-only accname + aria-describedby would fix); Space-on-knob gap kills the emergency path deepest in the board; #simple-cs-name has no live-region behavior. Good: real buttons, roving tabindex on pads and view switch, cold strip aria-hidden with text legend.

The confirmed non-engineer live operator: status sentence is 12px — smallest prose on the deck — against the product's own distance-readability gate; stage bypass silence hits hardest. Strong: plain language, honest cold face, arming under pressure, once-per-load headphone check.

## Minor Observations

- .simple-chip is a 999px pill — only non-functional radius in a 2/3/4px + circles system.
- Dual phrasing of one instruction on the cold screen ("Press Start to hear it" vs "Start to try a sound.").
- .preset-row-tags in display amber — small bleed of the one-machine-mouth rule (mono; likely intended).
- .safety-dialog 6px radius + 48px shadow deliberate but untokenized [P3]; either tokenize as off-chassis exception or align to 4px.
- Descriptions clamp at 2 lines in the 260px column with no expand.
- Legacy --text-primary token block coexists with --pm-* register (off-chassis dev surfaces; hygiene).

## Questions to Consider

1. If during a show nobody touches anything but Bypass, why does Bypass's richest feedback live in Advanced? What would it mean for the Simple stage itself to be the bypass instrument?
2. "One chain, one state, two control paths" — is it true when only one path is reversible?
3. The library is coverage-driven and will grow past 33. At what count do five hand-named filters break, and should filters be generated from the taxonomy axes so a coverage gap forces its own filter into the UI?

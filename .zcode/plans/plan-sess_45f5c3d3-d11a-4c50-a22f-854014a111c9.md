# Horizontal-default board, condensed portrait cards, per-card resize

## What changes, per file

**1. `src/canvas.js` — flow default + horizontal board mechanics**
- Flip the default flow to `horizontal`: `boardFlow` init (line 341), `readFlowPreference()` fallback (2278), `placeNewNode` (173), `loadModel` missing-flow fallback (2018-2019). The FLOW toggle keeps working exactly as now — flipping gives the vertical stacked reading (today's layout, unchanged). Persisted prefs win: an existing user with `vertical` saved keeps vertical.
- **Horizontal TIDY**: add a row-layout variant of `tidyStackLayout()` — `y = 16`, `x += cardWidth + GRID_PITCH`, seats in DOM order — selected when `boardFlow === 'horizontal'`. Vertical tidy math stays as-is.
- **X-extent**: extend `refreshBoardExtent()` (186-195) so horizontal mode maintains `chainListEl.style.minWidth = maxX + width + pitch` (today only minHeight exists — horizontal scroll would clip).
- **Per-card width + resize**: add `w` to layout entries (alongside x/y/scale/flow). A corner resize grip (bottom-right of each expanded card, drawn like the grip dot field, pointer-drag, snap-quantized to 16px, clamped 11–24rem) writes `positions[id].w`; `applyPositionToCard` also applies `card.style.width`. Autosave on resize-end (same path as move-end). Uniform default width 15rem (240px) when no `w` saved — every card the same size, so the horizontal row reads as even modules.

**2. `styles/main.css` — condensed portrait card anatomy for horizontal mode**
- `.canvas-panel.flow-horizontal .node-card`: width from the JS-applied px (default via CSS `15rem`), **grid becomes one column** — the rail collapses into a compact header row (grip · family code · label · badge · fold/eject pinned right) with the params field wrapping below. Portrait gestalt: `min-height: 16rem` (256px vs 240 wide — slightly taller than wide, per your spec), params field vertically centered when short.
- Trim rows become fluid in narrow cards (`width: min(10rem, 100%)`), pad groups already fold.
- Collapsed state in horizontal mode stays the slim groove line at card width.
- Resize grip styling: machined dot-field corner mark, `cursor: ew-resize`, touch-action none; hidden when collapsed.
- Vertical mode (the flipped reading) keeps the compact full-width stack from the last round untouched.

**3. `src/persistence.js` — store tolerance for `w`**
- `sanitizeLayout` accepts a finite `w`, clamps to the same 11–24rem px range, defaults absent → omit (CSS default). Additive field, no envelope version bump; older payloads load with default widths.

**4. Tests — update pins, add coverage**

- New checks: horizontal tidy row seats, X-extent minWidth, `w` round-trip + clamp + prune, resize-end saves once, jack geometry with custom widths (already live-measured, but pin it).

## Project idea

- Initial idea: VoxChain is a browser-based live vocal-chain builder. A home karaoke host tests a microphone, describes the desired sound in ordinary language, and an agent uses WebMCP to construct or tune the same visible, safe chain the person can inspect and control.
- Contest proof: The memorable result is the ratio between a simple WebMCP prompt and the complexity of the working vocal chain it produces.
- Primary contest user: A home karaoke host who understands the desired result but may not know how to configure EQ, compression, reverb, gain, and limiting manually.
